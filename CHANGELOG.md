# Changelog

Each SDK keeps its detailed changelog next to its code:

- Python (`collieai`): [python/CHANGELOG.md](python/CHANGELOG.md)
- Node.js (`@collieai/sdk`): [node/CHANGELOG.md](node/CHANGELOG.md)
- .NET (`CollieAi.Client`): [dotnet/CHANGELOG.md](dotnet/CHANGELOG.md)

The three SDKs share one version number and are released together. A release
that changes only one of them still ships all three; the others record that
they have no functional changes.

Starting with 2.2.0 the SDKs are licensed under MIT. Releases up to and
including 2.1.0 remain under Apache-2.0.
